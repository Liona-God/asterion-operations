# Security policy

Please do not open a public issue for a suspected vulnerability. Contact the repository owner privately with reproduction steps, affected paths, impact, and a safe way to verify the report. We will acknowledge credible reports, investigate them, and coordinate disclosure before publishing details.

This repository is an educational production-style baseline. Deployers remain responsible for identity, TLS, secret storage, patching, rate limiting, backups, incident response, and compliance controls described in [`docs/threat-model.md`](docs/threat-model.md).
